# Creative Union +44 CIC — website

Bilingual (Ukrainian / English) static website of Creative Union +44 CIC, London.

- `index.html`: the page; every text exists twice, `data-l="uk"` and `data-l="en"`
- `styles.css`: styles; brand colours are in `:root`
- `script.js`: language toggle, mobile menu, scroll animations
- `img/`, `media/`: images and videos

Published with GitHub Pages from the `main` branch, root folder.
